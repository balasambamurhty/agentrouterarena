● THE BENCHMARK

The benchmark

The unit is a trajectory, not a prompt. 14 task families, 51 seed scenarios. Each scenario encodes an evolving goal, injected world state, a capability pool, constraints, an allowed route set, and named failure modes.

shape

Multi-turn trajectory

2–4 turns with evolving goal and injected state per scenario.

oracle

Allowed route sets

Each turn lists expected routes and acceptable alternatives.

failure

Named failure modes

Every scenario targets specific routing failures.

families

10 task families

From goal clarification to stop detection.

schema

JSON Schema validated

Every scenario validated on load.

deterministic

Reproducible scoring

No LLM judge required in v0.1.

— SAMPLE SCENARIO

A goal-shift scenario, end to end

From benchmark/scenarios/goal_shift.yaml. The user changes objective mid-task; the router must re-plan rather than continue the original route.

# benchmark/scenarios/goal_shift.yaml
- id: ar_goal_shift_001
  family: goal_shift
  difficulty: medium
  user_goal: "Plan a weekend hiking trip near Palo Alto"
  available_agents: [research_agent, planning_agent, calendar_agent, safety_agent]
  constraints: { latency_budget: medium, cost_budget: medium, privacy: low }

  turns:
    - user: "Find a challenging hike near Palo Alto for Saturday."
      expected_router_actions:
        - route_to: research_agent
          reason: "Needs location-based options for strenuous hikes."
      acceptable_alternatives:
        - route_to: planning_agent
          reason: "Planning can scope the search parameters."

    - assistant_state: "Found Mission Peak and Black Mountain."   # injected world state
      user: "Actually make it family-friendly and include lunch nearby."
      expected_router_actions:
        - route_to: planning_agent
          reason: "Goal changed from challenging hike to family outing."

  success_criteria:
    - "Acknowledges the changed goal rather than continuing the strenuous-hike route"
    - "Produces a family-friendly plan with a lunch option"

  routing_failures: [stale_goal_continuation, wrong_specialist]
